# План реализации

1. Исследовать первичные источники, зафиксировать аудиторию, содержание, две самостоятельные сетки и правовые ограничения в DESIGN_SPEC.md.
2. Создать независимый React + Vite + TypeScript проект. Добавить локальные шрифты с лицензиями и собственную графику.
3. Реализовать все секции, якоря, мобильное меню, раскрытия, демоформу без ввода персональных данных и информационный диалог.
4. Проверить typecheck, ESLint, production build. Прогнать Playwright на 1440/768/390/320, меню, Escape, фокус, формы, FAQ, якоря, reduced motion, отсутствие overflow, ошибок консоли и запросов. Проверить axe и Lighthouse.
5. Сделать реальные скриншоты; визуально просмотреть desktop/mobile, исправить обнаруженные дефекты и повторить релевантные проверки.
6. Подготовить отдельный Git-репозиторий и GitHub remote, Netlify Free конфигурацию, production-архив. Публиковать только при доступной авторизации. Никаких платных услуг или доменов.
7. Проверить публичный HTTPS, прямое открытие и mobile после публикации. Если вход недоступен — зафиксировать блокер без имитации публикации.
8. Подготовить README, PORTFOLIO.md, ASSETS.md, QA_REPORT.md и DEPLOYMENT_REPORT.md с фактическими результатами.
