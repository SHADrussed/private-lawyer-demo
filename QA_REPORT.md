- Мобильное меню: открытие, aria-expanded, Escape, возврат фокуса, повторное открытие, переход и закрытие.
- Переключение трёх форматов консультации мышью, ArrowRight и Home; синхронизация с радиокнопками демоформы.
- Открытие/закрытие FAQ.
- Выбор значений формы, submit, честное локальное состояние и отсутствие отправки/хранения.
- Информационный dialog: открытие, Escape, возврат фокуса, повторное открытие и закрытие кнопкой.
- prefers-reduced-motion: нативные переходы без smooth scroll.
- Прямая загрузка `/#faq` с попаданием раздела в viewport.
- Перезагрузка очищает демонстрационный результат.

## Lighthouse — финальный замер

Мобильный профиль, стандартное моделирование сети/CPU Lighthouse, локальный production preview, один финальный проход после исправлений. Показатели могут отличаться на публичном хостинге.

| Метрика | Результат |
| --- | --- |
| Performance | 97/100 |
| Accessibility | 100/100 |
| Best Practices | 100/100 |
| SEO | 100/100 |
| LCP | 2.0 s |
| CLS | 0.001 |
| TBT | 50 ms |

Полный машинный отчёт: [docs/lighthouse-mobile.json](docs/lighthouse-mobile.json). Проверка выполнялась последовательно, после завершения E2E, чтобы параллельные браузеры не искажали CPU-замеры.

Для повторения замера: запустить `npm run preview -- --port 4162`, затем в другом терминале:

```sh
CHROME_PATH=/usr/bin/chromium npx lighthouse http://127.0.0.1:4162 --chrome-flags="--headless --no-sandbox --disable-dev-shm-usage" --only-categories=performance,accessibility,best-practices,seo --output=json --output-path=docs/lighthouse-mobile.json --quiet
```

## Визуальный аудит

Просмотрены реальные снимки первого экрана, содержательной секции, длинной страницы и мобильной версии. Для контрольных размеров 768/390/320 снимки находятся в `docs/audit`; три презентационных скриншота — в `docs/screenshots`.

Сохранена отдельная светлая редакционная система: антиква, тёплая бумага, терракота, вертикальная заметка и авторская линейная графика.

## Исправления, подтверждённые повторной проверкой

- Затемнены малоконтрастные подписи/номера: после правки axe проходит все четыре размера.
- Увеличен основной текст для mobile; сохранились переносы и нулевая горизонтальная прокрутка.
- Удалено переопределение доступного имени логотипа, которое исключало видимую подпись. Добавлена отдельная проверка этого правила.
- Мобильное меню раскрывается в потоке документа: его положение не зависит от высоты демоплашки.
- В тесте исправлен селектор кнопки меню, имя которой меняется на «Закрыть». Под нагрузкой увеличен timeout сценария до 60 секунд; повторный финальный прогон завершился без ошибок и повторов.
- Проверены лицензии локальных шрифтов; внешние фотографии и вымышленные профессиональные сведения отсутствуют.
