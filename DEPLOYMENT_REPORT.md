## Подтверждённые блокеры

GitHub CLI авторизован как `SHADrussed`, но попытка создать первый из двух репозиториев командой `gh repo create legal-bureau-demo --public` вернула:

```text
GraphQL: Resource not accessible by integration (createRepository)
```

Создание репозиториев недоступно текущей интеграции. Второй вызов с теми же полномочиями не выполнялся. Не создавались репозитории в чужих аккаунтах и не использовались обходные способы авторизации. Целевое имя данного репозитория: `private-lawyer-demo`.

Netlify: нет подключённого инструмента, NETLIFY_AUTH_TOKEN не настроен, сохранённая конфигурация авторизации отсутствует. Без владельца не создавались аккаунты, сайты и платные услуги. Токены не запрашивались в чате и не записывались в файлы.

## Минимальное действие владельца для публичной ссылки

1. Войти в собственный аккаунт Netlify и проверить, что выбран **Free**.
2. Открыть https://app.netlify.com/drop и загрузить **содержимое готового `private-lawyer-demo-dist.zip`** (распакованный каталог с `index.html` в корне). При необходимости явно включить публичную публикацию в Netlify: новые проекты могут начинаться приватными.
3. Дождаться публикации на выданном Netlify HTTPS-адресе. Не включать платные дополнения, auto recharge и не покупать домен.
4. Зафиксировать фактический URL и проверить сайт по списку ниже. В этом отчёте URL заранее не придумывается.

## Завершение GitHub и непрерывного деплоя

С исходным ZIP: распаковать проект, выполнить `git init -b main`, `git add .`, `git commit -m "Create legal demo"`. Либо восстановить готовую историю из одноимённого `.bundle` командой `git clone /path/to/private-lawyer-demo.bundle private-lawyer-demo`, затем удалить локальный bundle remote: `git remote remove origin`.

Внутри проекта, в терминале владельца с правами создания репозиториев:

```sh
gh auth login
gh repo create private-lawyer-demo --public --source=. --remote=origin --push
```

Если вход уже выполнен с нужными правами, `gh auth login` повторять не нужно. После этого в Netlify выбрать Add new project → Import an existing project → GitHub → `private-lawyer-demo`. Репозитории и сайты должны оставаться независимыми.

Настройки:

```text
Base directory: (корень репозитория)
Build command: npm run build
Publish directory: dist
Node.js: 22
```

`netlify.toml` уже содержит настройки сборки, CSP и HTTP-заголовки. Для загрузки готовой сборки без Git тот же набор заголовков включён в `dist/_headers` через `public/_headers`. Переменные окружения, секреты и backend этому демо не нужны. Прямые URL — `/` и якоря `/#about`/`/#faq`/`/#contact` по фактически существующим разделам. Отдельных клиентских маршрутов нет; SPA-rewrite не нужен.

## Проверки после входа владельца

- Открыть выданный **публичный** HTTPS URL в режиме инкогнито, убедиться, что не требуется Netlify login.
- Проверить `/` и прямое открытие `/#faq` и `/#contact`; открыть на ширинах 1440, 768, 390 и 320.
- Запустить `BASE_URL=https://ACTUAL-SITE.netlify.app npm run test:e2e` и повторить Lighthouse по фактическому HTTPS URL.
- Проверить заголовки ответов, локальные шрифты, отсутствие console/network errors и горизонтальной прокрутки.
- Проверить, что демоформа не делает запросов, не принимает персональные данные и честно сообщает об отсутствии отправки.
- Внести URL в этот отчёт, PORTFOLIO.md и README; добавить canonical/абсолютный OG URL, если они нужны для публичного концепта.

## Проверенные условия Netlify

По https://www.netlify.com/pricing/ на дату исследования: Free — $0 и 300 кредитов в месяц. Production deploy — 15 кредитов. Два первичных production deploy потребуют 30 кредитов при применимости текущей модели; трафик и остальные операции учитываются отдельно. При исчерпании лимита проекты могут приостанавливаться. У старых аккаунтов может быть Legacy-тариф — его фактические условия проверяет владелец.

Коммерческие проекты разрешены: https://www.netlify.com/blog/introducing-netlify-free-plan/ . Численные Legacy-лимиты из старой статьи не применяются к текущей оценке. На Free возможен служебный badge: https://docs.netlify.com/manage/projects/powered-by-netlify-badge/ . Никакой платёж или платная услуга в ходе работы не запускались.
