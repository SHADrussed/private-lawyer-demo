# Точка опоры — юридический демоконцепт

Светлый персональный сайт частной адвокатской практики. Редакционная антиква, тёплая бумажная палитра и спокойный путь от знакомства к выбору формата консультации.

**Статус: опубликован на Netlify Free и проверен по публичному HTTPS.**

Сайт: https://shadrussed-private-lawyer-demo.netlify.app

Публичные desktop/mobile проверки: [QA_REPORT.md](QA_REPORT.md).

Целевое имя GitHub-репозитория: `private-lawyer-demo`. Удалённый репозиторий пока не создан: интеграции недоступен `createRepository`. Локальный Git-репозиторий подготовлен.

## Локальный запуск

Node.js 22.12+ (в CI — Node 22), npm. У каждого проекта собственный package-lock.json; независимая сборка без общей библиотеки или monorepo.

```sh
npm ci
npm run dev
```

```sh
npm run typecheck
npm run lint
npm run build
npm run preview
npm run test:e2e
```

Для E2E локально используется `/usr/bin/chromium`. Если браузер находится иначе, измените `executablePath` в playwright.config.ts либо используйте `CI=true npx playwright install chromium`, затем `CI=true npm run test:e2e`. CI устанавливает Chromium автоматически. Для проверки опубликованного сайта: `BASE_URL=https://YOUR-SITE.netlify.app npm run test:e2e` (укажет удалённый URL, локальный сервер не запускается). Проверяйте именно Free и не включайте платные дополнения.

## Реализовано

- Полностью самостоятельная адаптивная композиция для 1440, 768, 390 и 320px.
- Все разделы, якоря, мобильная навигация с Escape и возвратом фокуса.
- Переключаемые форматы консультаций с доступными ARIA tabs и клавиатурной навигацией; выбор формата связан с демоформой.
- Нативный FAQ и информационный modal dialog с Escape, блокировкой фокуса браузером и возвратом к кнопке.
- Демоформа с честным локальным результатом: никаких полей для персональных данных, загрузок, отправки, API, хранения и аналитики.
- Skip link, семантическая разметка, focus-visible, prefers-reduced-motion, русские SEO/OG-метаданные и SVG favicon.
- Локальные WOFF2 с SIL OFL; авторская SVG/CSS-графика; внешних запросов на шрифты/изображения нет.
- Netlify build config, CSP и защитные HTTP-заголовки, GitHub Actions CI.

## Стек и структура

React 19 · Vite 7 · TypeScript 5.9 · современный CSS · Playwright · axe-core · ESLint · Lighthouse.

## Адаптация под клиента

1. Заменить название, направления и тексты на согласованные с адвокатом материалы.
2. Добавить настоящее имя, фотографии с правами использования, подтверждённые сведения о статусе, образовании и профессиональном пути.
3. Указать проверенные регистрационные сведения, адвокатскую палату, адрес и фактические способы связи. Не подставлять случайные данные в шаблон.
4. Согласовать содержание с актуальной статьёй 17 КПЭА и 63-ФЗ. Не добавлять отзывы, сравнения, гарантии результата или непроверенные достижения.
5. Форму подключать отдельной задачей: определить оператора, правовое основание обработки, политику, необходимые согласия, хранение, локализацию и защищённую передачу. Пока backend отсутствует, сохранять демомаркировку.
6. После юридического и контентного согласования заменить демопояснения; обновить canonical, абсолютный og:image, домен и sitemap для URL реального клиента. Повторить тесты на опубликованном сайте.

Демонстрационный контент не является юридической консультацией. Сайт не представляет реальных адвокатов; юридическая помощь не оказывается.

## Повторная публикация

Сайт развёрнут напрямую из production-сборки; GitHub для текущего хостинга не требуется. Для Netlify CLI 27 использовался Node 24. Приложение и GitHub CI собираются на Node 22.12+; серверный build в Netlify также настроен на Node 22.

```sh
npm run build
npx netlify-cli@27.13.0 login
npx netlify-cli@27.13.0 deploy --site shadrussed-private-lawyer-demo --dir dist --prod --no-build
```

Существующий вход повторять не нужно. CLI хранит авторизацию в своём глобальном профиле, который не входит в этот репозиторий. `.netlify` игнорируется. Альтернатива — импортировать GitHub-репозиторий в тот же проект Netlify после появления прав на его создание.
